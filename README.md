# i.client

VPN-клиент для Android. Разработчик: I.Zed. Приложение разработано с помощью Codex.

## Установка и обновления

**Исправление установки в 1.3.2.** У приложения удалено право устанавливать другие
APK. В контрольных сборках на эмуляторе это разрешение вызывало блокировку Google
Play Защитой даже без кода и библиотек. Полный исправленный APK 1.3.2 установлен
штатным установщиком с включённой защитой. Это результат проверки на эмуляторе,
не гарантия одинакового решения на каждом устройстве. Отключать защиту не нужно.
Прежние релизы и файлы сохранены без изменений.

Скачайте **i.client.apk** из [Releases](https://github.com/ivwhaichy/i.client.1.0/releases).
Устанавливайте поверх прежней версии с той же подписью, не удаляя приложение:
так сохранятся ваши подключения и настройки. Android попросит разрешить установку
из выбранного источника. Если подпись не совпадает, не удаляйте рабочий клиент.

Начиная с **1.3.0**, i.client проверяет стабильные релизы при запуске (не чаще
раза в 12 часов) и периодически через WorkManager при наличии сети. Найденное
обновление показывается при открытом приложении; скрытой загрузки APK нет.
Ручная проверка: **главная → i → проверить обновления**.
С **1.3.2** после согласия APK скачивается через браузер с GitHub. i.client
повторно проверяет сведения о стабильном выпуске перед переходом к скачиванию,
но не запрашивает право установки других приложений и не запускает установщик
самостоятельно. Открытие скачанного APK, проверку подписи и подтверждение установки
выполняет Android. При первом скачивании Android может запросить разрешение
установки для браузера. Во время обновления VPN может прерваться.
Установка поверх версии с той же подписью сохраняет данные приложения.

В 1.3.0–1.3.1 использовались встроенная загрузка, проверка SHA-256/подписи и
запуск установщика из i.client. Новый APK можно получить и через этот механизм;
после обновления приложение переходит на загрузку через браузер.

Версии до 1.3.0 нужно один раз обновить вручную, затем будет доступно обновление
из приложения. В этом репозитории нет токенов GitHub или ключа подписи.

## Возможности

- VLESS REALITY / XTLS Vision, Hysteria/Hysteria2, VMess, Trojan, Shadowsocks.
- Импорт самодостаточных OpenVPN `.ovpn` с inline-сертификатами и ключами.
- Несколько профилей, веб-панель и раздельное туннелирование приложений.
- Светлая, тёмная и системная темы; настройки справа сверху (с 1.3.1).
- Опциональный экспериментальный VK TURN для Hysteria2. Его доступность и
  пропускная способность не гарантированы; CAPTCHA проходится вручную.

OpenVPN: только TUN; без внешних файлов, скриптов, TAP, PKCS#12, зашифрованных
приватных ключей и произвольных клиентских маршрутов. Старый LZO поддерживается
только на приём; смена адреса peer на лету не реализована.

## Исходники и лицензии

Этот репозиторий используется для распространения релизов, а не рабочей
Git-истории. Соответствующие исходники Android-приложения, sing-box 1.14.4,
изменённого vk-turn-proxy и их Go-зависимостей находятся в архиве
**i.client-source-VERSION.zip** в том же Release. Там есть инструкции и скрипты
сборки. Исходные JAR Android/Kotlin-библиотек и apksig доступны дополнительно
в **i.client-jvm-sources-VERSION.zip**. Автоматические архивы GitHub «Source code»
содержат только страницу релизов, не исходники приложения.
Скачивание исходников доступно на тех же условиях доступа, что и APK.
